🍭 Shrividya's Food Blog
Welcome to Shrividya's Food Blog – a sweet and simple HTML & CSS-based personal blog site that brings out the love for food, especially candies! 🍬

🌟 Features
Responsive and clean layout using Quicksand font
Mobile-friendly with media queries
Eye-catching full-screen background image
Navigation bar with links to Home, Blog, and About Me
Simple, aesthetic color palette for a cozy vibe

📂 Folder Structure
├── index.html
├── blog.html
├── css/
│   ├── style.css
│   └── fontawesome.zip/ (if used)
├── images/
│   └── candies.jpg

💡 How to Use
Clone the repo:
git clone https://github.com/your-username/shrividyas-food-blog.git
Open index.html in your browser.
Customize content or styles as needed.
